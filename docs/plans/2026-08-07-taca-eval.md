Each task is TDD-first (RED → GREEN → REFACTOR) and lands as its own signed commit.

## Task A — Transparency eval logic (`internal/okf`)

**Files:** `internal/okf/eval.go` (new), `internal/okf/eval_test.go` (new).

- `EvalFinding{Check, Path, Message}` (mirrors `LintFinding`).
- `EvalTransparency(b *Bundle, opts EvalOptions) []EvalFinding`, sorted by
  (path, check), never mutates the bundle. Sub-checks:
  1. `evalGradeMissing` — node with neither `epistemic` nor `authority`.
  2. `evalGradeVocabulary` — `epistemic`/`authority` value below the outlier
     floor of the corpus-observed distribution. Vocabulary derived per-bundle
     (`observedGradeVocabulary`), floor a calibrated constant.
  3. `evalUncited` — node with zero provenance: no `Sources()`, no legacy
     `# Citations`, no inline internal `/…` node reference.
  4. `evalCitationUnresolved` — a `sources[].resource` (or legacy citation) that
     is a bundle-internal path (`/…` / `.md`) resolving to no node.
- RED first: table tests for each sub-check on hand-built `*Bundle`s (planted
  positive + planted clean). At least one produces a REAL failure message naming
  the missing behavior (not an incidental error path).

## Task B — Sampler + eval-set scaffold (`internal/okf`)

**Files:** `internal/okf/eval_sample.go` (new), `internal/okf/eval_sample_test.go` (new).

- `EvalSample(b *Bundle, opts SampleOptions) []NodeEvalScaffold` where each
  scaffold carries: path, title, description, grades (`epistemic`/`authority`/
  derived `TrustTier`), the node's sources, extracted top claims, and empty
  slots (`AccuracyClaims[].ExpectedGrounding`, `AlignmentAnswered`,
  `CalibrationHolds`) for the judge.
- Selection: `--sample N` deterministic (seeded `math/rand`); `--changed-since`
  is resolved in the cmd layer (git) and passed as an explicit node-path set to
  keep `internal/okf` git-free and testable.
- Claim extraction: `**bold**` assertions + heading-anchored lines from
  `proseBody`, capped, deterministic order.
- RED first: seeded sample of N over a fixture is reproducible; scaffold shape
  populated from a node; empty slots present.

## Task C — `okfctl eval` command (`cmd`)

**Files:** `cmd/eval.go` (new), `cmd/eval_test.go` (new), wire into `cmd/root.go`.

- `newEvalCmd()` parent with `transparency` + `sample` subcommands.
- `transparency`: `--strict`, `--json`, `--coverage`-style flags reuse
  `loadBundleForCmd` + `addNoIgnoreFlag`; JSON is a sorted `[]EvalFinding`
  (never null); `--strict` returns an error on findings. Mirrors `lint.go`.
- `sample`: `--sample`, `--seed`, `--changed-since`, `--format json|md`. `md`
  emits a reviewer worksheet; `json` emits the scaffold array. `--changed-since`
  resolves changed node paths via `git diff --name-only <ref>` scoped to the
  bundle dir.
- RED first: `--strict` exit on planted finding; `--json` shape; `sample --format md`
  contains the three dimension headers; unknown subcommand errors.

## Task E — Whole-increment E2E + calibration

- Build the binary; run `eval transparency --json ./bundles/knowledge` against the
  real 239-node corpus; **count findings by check** (increment-8 precision gate):
  the output must be defensibly real, not a noise flood. Calibrate the
  vocabulary-outlier floor against the measured `epistemic`/`authority`
  distribution and co-locate the measurement at the constant + in the spec.
- Run `eval sample --sample 5` and `--changed-since` against the corpus; capture
  the scaffold output as evidence.
