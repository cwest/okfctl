# Spec: `okfctl analyze` — the proactive curation report

## Problem

`lint` answers *"is this corpus broken?"* — a GATE (binary, CI-shaped,
`--strict` exits non-zero). It deliberately does not answer *"where is this
corpus WEAK?"* — a REPORT (ranked, human-shaped, feeds new research work).

The `okf-curation` skill still shells out to a bespoke 577-line
`tools/okf_analyze.py` for that report. Two of its five curation dimensions —
**freshness** and **tag-cluster synthesis** — have no okfctl equivalent at all.
This command brings the report into okfctl as a first-class core command.

## Command

```
okfctl analyze [bundle-dir] [flags]
```

Report semantics, NOT gate semantics: **`analyze` exits 0 whenever the analysis
runs successfully, regardless of how many findings it produces.** The exit code
reflects whether the analysis succeeded, not whether the corpus is perfect. This
is the hard discriminator from `lint --strict`, and it must never be blurred:
there is no `--strict` on `analyze`.

### Flags

| flag | default | meaning |
|---|---|---|
| `--json` | false | emit machine-readable JSON instead of the human report |
| `--stale-days` | 180 | age (days) past which a node's `modified` is flagged stale |
| `--time-sensitive-fraction` | 0.5 | surface a time-sensitive node once its age ≥ fraction × stale-days; undated marked nodes always surface |
| `--thin-lines` | 15 | body line count below which a node is "thin" |
| `--cluster-min` | 3 | min nodes sharing a tag to flag a synthesis cluster |
| `--coverage-threshold` | 3 | (delegated to lint) distinct-node mention count for a coverage gap |

## Five dimensions

Take `tools/okf_analyze.py` as the REFERENCE FOR INTENT, not code to port
verbatim. Reuse okfctl internals where a dimension overlaps `lint`; do not
duplicate logic.

1. **Coverage / gaps**
   - *dangling forward-links* — a node body links to a `.md` target that
     resolves to no node (referenced-but-unwritten knowledge, OKF §5). NEW to
     analyze; `lint`'s `missing-xref` is the inverse (a mention with no link).
   - *thin nodes* — body line count < `--thin-lines`.
   - *single-citation / uncited nodes* — citation entries under `# Citations`.
   - *known coverage gaps* — delegated to `okf.Lint` `coverage-gap` (no reimpl).

2. **Freshness** — NEW capability.
   - *stale* — `modified` older than `--stale-days`; undated nodes flagged softly.
     Basis field order: `modified` → `created` (fallback for un-timestamped edits).
   - *time-sensitive* — body carries a time-sensitive marker AND has aged past
     `--time-sensitive-fraction × --stale-days`; undated marked nodes always
     surface. Reads the package clock seam (`nowUTC`) so tests pin "now".

3. **Connectivity**
   - *orphans* — no inbound and no outbound in-bundle links. Reuses lint's
     `inboundCounts` (the single source of truth for inbound), so analyze and
     lint can never disagree about what is orphaned.
   - *weakly-linked* — exactly one total in-bundle link (in + out).

4. **Clusters / synthesis** — NEW capability.
   - tag co-occurrence: a tag shared by ≥ `--cluster-min` nodes with no node
     tying them together is a synthesis-overview candidate.

5. **Structure**
   - *duplicate titles* — nodes whose titles fold to the same alphanumeric key.
   - *near-duplicate slugs* — node base names within edit-distance 1 of each other.

## Non-goals (deliberately out of scope vs the Python reference)

The card names exactly five dimensions. The reference additionally computes
graph-richness metrics (clustering coefficient, modularity, Adamic-Adar
should-link suggestions). Those are NOT in the card's five-dimension surface and
are out of scope for this command. Keeping to the five keeps the report
actionable and avoids shipping metrics the card did not ask for.

No new Go dependencies. No CGO. Nothing model-requiring.

## Divergence to expect vs `okf_analyze.py`

- Freshness basis: analyze uses `modified` → `created`; the Python also falls
  back to a legacy `timestamp` field. The corpus completed its `timestamp` →
  `created`/`modified` migration (parent card t_6305666d), so the legacy field
  no longer exists on the real corpus and the fallback is dead weight here.
- Reserved-file link handling: analyze resolves links through okfctl's shared
  scanner, which already excludes reserved `index.md`/`log.md` targets, so those
  never appear as dangling links.
- Any freshness count difference against the Python is EXPLAINED in the PR
  handoff, not assumed correct on either side.
