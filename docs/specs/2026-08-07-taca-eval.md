# Spec: `okfctl eval` — a TACA-style trustworthiness eval pass for KB nodes

## Problem

`validate` checks a bundle against the OKF spec floor (format + link integrity)
and `lint` reports curation health. Neither checks whether a node is **true**. A
fluent, well-cited, *wrong* node passes both. For a corpus that serves as durable
ground truth, that is the highest-leverage integrity gap — and two independent
frameworks name it: the *Architected Intelligence* Observability lens (decompose
node trust via **TACA** — Transparency / Accuracy / Calibration / Alignment) and
the OWASP-LLM risk lens (LLM04/LLM09: ground-truth integrity is defended only by
human review + CI conformance, neither of which checks correctness).

This command converts "trust the curator + CI" into "trust, **and measure the
trust**" — as far as a pure-Go, offline, no-model tool honestly can.

## The hard architectural constraint (why TACA splits)

`okfctl` is pure Go, no CGO, **no model runtime, and no network** in its gate
commands (`validate`/`lint`). Truth-checking a claim against a cited source
inherently requires either reading the source (network) or judging semantic
support (an LLM). okfctl must not do either from its own process. That constraint,
not a lack of ambition, is what partitions TACA:

| Dimension | What it asks | okfctl-native (offline, deterministic)? |
|---|---|---|
| **Transparency** | Is provenance present and do citations resolve? | **YES** — a real gate. |
| **Accuracy** | Are the node's claims supported by the cited source? | **NO** — needs source content / a judge. |
| **Alignment** | Does the node answer the question it set out to? | **NO** — needs semantic judgment. |
| **Calibration** | Do our `VERIFIED` labels hold up on re-check? | **NO** — needs re-verification + sampling over time. |

The honest design: **gate Transparency deterministically; scaffold — do not fake
— the other three.** okfctl emits a structured eval-set for a human or an
out-of-band LLM judge to complete for Accuracy/Alignment/Calibration. It never
prints a truth verdict it did not actually compute.

## Command

```
okfctl eval transparency [bundle-dir] [flags]   # the deterministic gate
okfctl eval sample       [bundle-dir] [flags]   # the spot-check scaffold
```

`eval` groups the two the way `node`/`index`/`log` group their verbs.

### `okfctl eval transparency` — the gate

Gate semantics, mirroring `lint`: advisory (exit 0) by default; `--strict` exits
non-zero on any finding; `--json` emits a sorted finding array. Findings, each an
`EvalFinding{Check, Path, Message}`:

- **`grade-missing`** — a concept node carries **neither** an `epistemic` grade
  **nor** an `authority` grade. Provenance is invisible: TACA-Transparency's floor.
- **`grade-vocabulary`** — a node's `epistemic` or `authority` value is outside
  the observed corpus vocabulary (a typo / drift: e.g. `authority: high`, a
  lowercase `authority: verified`). Surfaced, never spec-gated (§11 forbids
  rejecting a bundle for an optional/unknown key) — this is *soft* guidance like
  `lint`'s status-lifecycle check, hard **only** under `--strict`.
- **`uncited`** — a concept node makes external claims but carries **zero**
  citations (no `sources` entries and no legacy `# Citations` list and no inline
  `/…` node references). A node asserting facts with no provenance trail.
- **`citation-unresolved`** — a `sources[].resource` (or a legacy `# Citations`
  internal `/…` entry) points at a bundle-internal node path that resolves to **no
  node**. This is link-*fit* for internal citations — a citation promising a
  sibling node that does not exist. External `http(s)` sources are out of scope
  (checking them needs the network; that is the sampler's/human's job).

Grade vocabularies are **derived from the bundle**, not hardcoded: the check reads
every `epistemic`/`authority` value in the corpus, treats the dominant set as the
vocabulary, and flags rare outliers below a small floor. This keeps the tool from
inventing an enum the spec deliberately does not define, while still catching the
one-off typo. (Rationale + the measured distribution live at the constant.)

### `okfctl eval sample` — the scaffold

Selects a spot-check sample and emits a structured eval-set (JSON or Markdown
worksheet) that a human or an out-of-band LLM judge completes. It **computes no
truth verdict.** Selection modes:

| flag | meaning |
|---|---|
| `--changed-since <git-ref>` | sample nodes changed since a ref (new/changed-node path) |
| `--sample <N>` | a deterministic pseudo-random sample of N nodes (seeded by `--seed`) |
| `--seed <int>` | seed for reproducible sampling (default 0 ⇒ derive from bundle) |
| `--format json\|md` | machine eval-set vs. a human worksheet (default json) |

For each sampled node the scaffold emits the three un-automatable dimensions as
prompts to fill in, pre-populated with what okfctl *can* extract:

- **Accuracy** — the node's cited sources + its top factual claims (heuristically,
  its bolded/`**…**` and heading-anchored assertions), one `expected_grounding`
  slot per claim for the judge to confirm the source supports it.
- **Alignment** — the node's `title`/`description` (the question it set out to
  answer) + a `does_body_answer_it` slot.
- **Calibration** — the node's current grade (`epistemic`/`authority`/derived
  `TrustTier`) + a `holds_on_recheck` slot, so a periodic sample measures whether
  the `VERIFIED` rate is calibrated.

`--changed-since` is the curation/CI hook: a pre-merge job runs
`eval transparency --strict` as a gate and `eval sample --changed-since origin/main`
to drop a worksheet for the human/LLM reviewer on the touched nodes.

## Where it plugs into the flow

- **CI gate:** `okfctl eval transparency --strict ./bundles/knowledge` joins
  `validate --strict` + `lint --strict` as a third conformance gate. It is the
  first machine gate that touches trust rather than format.
- **Curation sweep:** the `okf-curation` Mode-1 transaction runs
  `eval transparency` on the touched node before the atomic PR, and
  `eval sample --changed-since` to produce the spot-check worksheet the sweep
  files/attaches.
- **Standing calibration:** a periodic (e.g. cron) `eval sample --sample N` draws
  a re-verification sample across the corpus to measure Calibration over time.

## Scope boundaries — what this deliberately does NOT do

- **No truth verdict from okfctl.** Accuracy/Alignment/Calibration are *scaffolded*
  for an external judge; okfctl never claims a node is correct. Faking that would
  violate the no-model/no-network contract and mislead.
- **No network.** External `http(s)` citation liveness/link-fit is out of scope for
  the gate (it belongs to the human/LLM sampler pass, cf. `verifying-citation-link-fit`).
- **No new frontmatter field, no enum gate.** The grade vocabulary is observed from
  the corpus, never spec-enforced; `validate` is untouched. §11 is respected.
- **Not a full grader for the whole corpus.** The sampler is a *spot-check* by
  design; `transparency` is O(corpus) but purely structural.
- **No auto-fix / mutation.** `eval` is read-only, like `lint`/`analyze`.

## Testing

TDD, table-driven, against a small in-repo fixture bundle plus a captured run
against the real `cwest/knowledge-base` corpus to (a) prove the gate is
honest (precision-counted findings, no noise flood — the increment-8 lesson) and
(b) calibrate the vocabulary-outlier floor against the real value distribution.

### Measured evidence (re-run 2026-08-09, corpus HEAD `895693b`, 246 nodes)

`eval transparency` over the live corpus: **2 findings, both `grade-vocabulary`**
— `design/spacing-rhythm-and-density.md` (`authority: "DEPRECATED"`) and
`design/ux-psychology/deceptive-patterns.md` (`authority: "high"`), each an
off-vocabulary value carried by only 1 node. `--strict` exits 1; advisory exits
0. No `grade-missing`, `uncited`, or `citation-unresolved` findings remain — the
dangling internal citations counted in the original 2026-08-07 sweep (23
`citation-unresolved`, 8 `uncited`) were since fixed upstream in the corpus.

Vocabulary-floor sweep re-run against the same corpus confirms the default of 2
still holds: floor 1 → 0 findings (no value has <1 carrier, so nothing can fire);
floor 2 → the 2 genuine count-1 outliers above; floor 3 → 8 findings, the extra 6
being legitimate count-2 grades (`epistemic: draft`, `epistemic: active`,
`authority: SYNTHESIS`) false-positived. So 2 remains the value that isolates
real count-1 drift without punishing small-but-real vocabulary.
